# Contributing to Awesome Python

We welcome contributions to Awesome Python! This document outlines the process to help you get started.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes (e.g., add a new library, fix a typo).
4. Ensure your changes follow the guidelines below.
5. Commit your changes with a clear and descriptive message.
6. Push your branch and open a pull request.

## Guidelines

- **Quality**: Only add libraries that are actively maintained, well-documented, and widely used.
- **Format**: Keep the list alphabetical within each category. Use the format `[Name](link) - Description.`
- **Descriptions**: Keep descriptions concise and factual. Avoid marketing language.
- **One item per pull request**: This makes review easier.
- **Check for duplicates**: Before adding, search the list to ensure it's not already included.

## Code of Conduct

Please note that this project has a Code of Conduct. By participating, you agree to abide by it.

## Questions

If you have any questions, feel free to open an issue.

Thank you for contributing!
