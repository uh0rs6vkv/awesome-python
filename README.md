# Contributing Guidelines

Thank you for considering contributing to Awesome Python! Please take a moment to review these guidelines before submitting a pull request.

## Guidelines

- **Quality**: Only add high-quality, actively maintained Python projects and resources.
- **Search**: Search existing entries before submitting a PR to avoid duplicates.
- **Format**:
  - Add entries in alphabetical order within their category.
  - Follow the standard format: `* [Name](URL) - Short, objective description.`
  - Keep descriptions concise, objective, and ending with a period.
  - Avoid marketing speak (e.g., "the best", "awesome", "fastest").
- **Categorization**: If a suitable category doesn't exist, feel free to suggest one in your PR description.
- **New Projects**: New projects should generally have established usage or active maintenance.

## Pull Request Checklist

1. [ ] Check if the project is already listed.
2. [ ] Ensure the entry is placed in alphabetical order.
3. [ ] Check spelling and grammar.
4. [ ] Ensure build/lint checks pass.

Thank you for helping keep Awesome Python awesome!
